# Implementation Plan: Verify a Chart

## Overview

Add a second verification flow to the Veritas ID Next.js 14 app. The implementation follows a strict dependency order: API routes first (no UI dependencies), then shared components, then result pages, then minimal additions to existing files. All new code lives in new files except for two additive-only changes to `app/page.tsx` and `app/layout.tsx`.

## Notes

- Tasks marked with `*` are optional property-based tests — skip them for the hackathon MVP.
- The two changes to existing files (`app/layout.tsx`, `app/page.tsx`) are purely additive — no existing logic is altered.
- `ScanCard` and `IDCard` are internal to `VerifySection.tsx` and are not exported, satisfying the flow independence requirement (Requirement 9).
- `sessionStorage` keys `veritas_scan_result` and `veritas_id_result` are intentionally distinct to prevent cross-flow contamination.
- `ChartCard` is an async server component — result pages are client components that render it inside a `<Suspense>` boundary.
